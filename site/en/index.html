Features

Aiming for Arc's organization and interaction feel, starting with everything needed for everyday browsing.

Vertical tabs & Favorites

Today and Pinned tabs, up to 12 Favorites, and nested folders keep tabs organized.

Spaces & Profiles

Give each Space an icon and color. Profiles isolate cookies and login state.

Command bar

Enter URLs, search, jump to an existing tab or run commands from a single field.

Split view

Show two tabs from the same Space side by side.

Archive & restore

Closed Today tabs go to the Archive. Your layout is restored at launch.

Chrome extensions

Add Manifest V2 / V3 extensions through WebKit's Web Extension API, including by Chrome Web Store ID or URL.

The alpha has a single window. Multiple windows, private browsing, auto-archive, Arc import, AI, sync and Boosts are not available yet.

Install

Open the downloaded DMG and copy the app to Applications.

OS
macOS 15.4 or later
Chip
Apple Silicon (M1 or later). Intel Macs are not supported.
License
MIT
  1. Download and open the DMGGet choco-browser.dmg with the download button above and double-click it.
  2. Drag to ApplicationsDrag choco-browser onto the Applications folder in the window that opens.
  3. First launch: allow it with "Open Anyway"The alpha is not notarized by Apple yet, so macOS blocks the first launch.
    Open choco-browser from Applications and dismiss the warning. Then open System Settings → Privacy & Security, click Open Anyway near the bottom, and authenticate with your password or Touch ID. It launches normally from then on.
Prefer the Terminal? This does the same thing: 
xattr -dr com.apple.quarantine /Applications/choco-browser.app
To verify your download, put choco-browser.dmg.sha256 from the release page next to choco-browser.dmg and run: 
shasum -a 256 -c choco-browser.dmg.sha256

Privacy

No account registration, sync, AI uploads, usage tracking or remote search suggestions from choco-browser itself.

Your data stays local

Your tab layout is stored in Application Support on your Mac. Cookies live in a per-Profile WebKit data store and are never copied between Profiles.

Search only when you ask

Only web searches you explicitly run are sent to Google. Regular page loads are handled by WebKit.
