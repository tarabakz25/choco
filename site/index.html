主な機能

Arc の整理・操作体験を目指して、まず「日常のブラウジングが成り立つ」ところまで作りました。

縦タブと Favorites

Today と Pinned、最大12件の Favorites、階層フォルダでタブを整理します。

Space と Profile

Space ごとにアイコンと色を設定。Profile ごとに Cookie とログイン状態を分離できます。

コマンドバー

URL 入力、検索、既存タブへの切替、操作コマンドを1つの入力欄から。

Split

同じ Space の2つのタブを並べて表示します。

Archive と復元

閉じた Today タブは Archive に保存。起動時には前回の構成を復元します。

Chrome 拡張機能

WebKit の Web 拡張 API で Manifest V2 / V3 の拡張機能を追加できます。Chrome ウェブストアの ID や URL からも導入可能です。

α版は単一ウィンドウです。複数ウィンドウ、プライベート閲覧、自動 Archive、Arc からのインポート、AI、同期、Boosts は未対応です。

主な操作

⌘T新しいタブ・検索・既存タブ候補
⌘L現在ページの URL 入力
⌘W / ⇧⌘TToday を Archive / 閉じたタブを復元
⌃Tab / ⌃⇧Tab最近使った順にタブを切替
⌃⌥← / ⌃⌥→Space を切替
⌘F / ⌘R / ⌘Sページ内検索 / 再読み込み / サイドバー切替

インストール

ダウンロードした DMG から Applications にコピーするだけです。

対応 OS
macOS 15.4 以降
対応チップ
Apple Silicon（M1 以降）。Intel Mac は未対応です。
ライセンス
MIT
  1. DMG をダウンロードして開く上の「macOS 版をダウンロード」から choco-browser.dmg を取得し、ダブルクリックで開きます。
  2. Applications にドラッグ開いたウィンドウの choco-browser を Applications フォルダへドラッグします。
  3. 初回起動: 「このまま開く」を許可現在のα版は Apple の公証を受けていないため、初回は macOS にブロックされます。
    Applications から choco-browser を開いて警告を閉じ、システム設定 → プライバシーとセキュリティ を開いて、下部に表示される 「このまま開く」 を押し、パスワードまたは Touch ID で認証します。次回以降は通常どおり起動できます。
ターミナルを使う場合は、次のコマンドでも同じ結果になります。 
xattr -dr com.apple.quarantine /Applications/choco-browser.app
ダウンロードの整合性を確認するには、リリースページの .sha256 ファイルを同じフォルダに置いて実行します。 
shasum -a 256 -c choco-browser-0.1.0.dmg.sha256

プライバシー

choco-browser 独自のアカウント登録、同期、AI への送信、利用状況の収集、外部検索候補の取得はありません。

データは手元に

タブ構成は Mac 内の Application Support に保存します。Cookie などは Profile ごとに WebKit のデータストアへ保存され、Profile 間でコピーされません。

検索は明示したときだけ

あなたが実行した Web 検索のみ Google に送られます。Web サイトへの通常の通信は WebKit が行います。
