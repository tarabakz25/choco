# Figma UIへの改修

対象: [OSS-Arc / Layouts](https://www.figma.com/design/ZF9ydApZS6Ln3SRZFO2dWk?node-id=14-1052)。既存α版の機能を保ちながら、SwiftUIの画面をデザインへ合わせる。

## 対応した画面

- メイン／サイドバー（20:1138、19:1026）: 12.5rem(200pt)を初期幅とするグレーのサイドバー。戻る・進む・再読み込み・URL入力を左へ集約。Favoritesは3列、タブとフォルダは32ptの行。
- コマンドバー（20:1497、20:1676）: 中央の668×283pt、5行表示とスクロール。ページ側だけ55%暗くし、サイドバーの色は維持。⌘Lは現在のProfileで移動し、他Spaceへの切替は明示選択。
  入力中の候補は「開いていたタブ（開いているタブ→アーカイブ）→入力文字と関連検索（Googleサジェスト）→Googleが返す上位リンク→コマンド」の順。検索文字だけをデバウンスして送信し、URLとして解釈できる入力は送らない。
- サイト操作（20:1751）: 220pt幅。クイック操作の4タイル（共有・Boost・スクリーンショット・範囲キャプチャ）、拡張機能（インストール済みと「＋」）、Boost、設定（デベロッパーモード・自動PiP）、接続状態ピルと「…」をFigmaどおりに並べる。共有・スクリーンショット・拡張機能・デベロッパーモードは実際に動く。Boost・範囲キャプチャ・自動PiPのようにまだ機能がないものは見た目だけFigmaどおりにし、押すと「未対応」の通知を出す。URLのコピー・タブの固定・お気に入り・ページ内検索・Splitは「…」メニューにまとめた。URL欄はページを開いているとき、ホスト名の後ろにリンクアイコン（URLをコピー）と20ptのサイト操作タイルを置く。Figmaの入場モーションを一度だけ再生し、動きを減らす設定に対応。
- Archive（20:2202）: 96pt rail＋266pt panel。実際のArchiveを検索・Space絞込・日付別表示・復元。右のWebページを表示したまま利用できる。
- Space名（156:1704）: 28ptの「Space名」ラベル（11pt Semi Bold）は、お気に入り（タイルでも空のヒントでも）の下、固定タブ・フォルダの上に常に出す。
- 空の状態（157:7042）: お気に入りが0件のときは点線のヒント（背景は黒12%、点線は白30%、ドラッグでタブを追加／×で閉じる）、タブ・フォルダが無いSpaceでは選択色なしの「新しいタブ」を表示し、「クリア」は隠す。
- 新規作成メニュー（149:6932）: 下部の＋を押すと、Spaceの作成シートではなく「新しいSpace／フォルダ／Easel／Boost／Split／タブ」のメニューを開く。＋は45°回転して×になり、メニューは0.28秒のスプリング（0.96倍・下11pt→0）と、行ごとの30ms遅れのフェード・4pt上昇で現れる。外側のクリック・Esc・もう一度＋で閉じる。Figmaどおり`^⇧E`（Easel）・`^⇧;`（Split）・`⌘T`を表示し、`^⇧;`と`^⇧E`は実際にメニューバーのキーとして使える。Easelはまだ機能がないので、押すと「未対応」の通知を出す。Splitは現在のタブの隣に空のタブを作ってアドレス入力へ進む（すでにSplit中は無効）。
- サイドバーの行・ボタンの状態（Figma「A. Sidebar」6:254）: 通常は背景なし、ホバーは白5%（`ChocoTheme.hover`）、選択・押下は白12%。「新しいタブ」・フォルダ・タブの各行とツールバー・下部ボタンが対象。タブ行はホバーのときだけ右端に20ptの×（閉じる）を出し（選択中でもホバーしていなければ出さない）、選択中の行では×に5%の背景を付ける。お気に入りタイルは通常6%・ホバー7%・選択12%・押下12%（アイコン12pt、不透明度92%）で、56×40pt・縦横8pt間隔。URL欄は、ページが無いとき検索アイコンとプレースホルダだけ、ページを開くとアドレス・リンク・サイト操作タイル（常に12%）を出し、ホバーで7%→12%。戻る・進むの無効は35%。Spaceドットは全Spaceがアイコン（現在は不透明、ほかは40%）で、現在のSpaceの下に10×2ptの白60%のインジケータを出す。
- ボタンの押下状態: サイドバーのアイコン・行・Spaceボタンは`ChocoPressStyle`で押下中に選択色を重ねる（無効なボタンは対象外、動きを減らす設定ではアニメーションなし）。
- サイドバー非表示／ホバー表示（22:2812、22:3001）: 8pt(`ChocoSpace.sm`)のコンテンツ余白、左端での一時表示、表示ボタンと⌘Sで固定表示へ戻る。
- 設定ポップアップ（105:16398、105:16494、105:16716、105:16865）: 684×650ptの独立ウィンドウ。General / Profiles / Shortcuts / Advancedの4タブ、暗いツールバーと紫の選択色を再現。⌘,とサイドバーの設定メニューから開く。

機能のない項目（Media・ダウンロード管理・Easel・Boost・自動更新・プレビュー・終了確認など）も、Figmaと同じ見た目・配置で表示し、操作すると「未対応」の通知（`UnsupportedNotice`）を出す。無効（グレー）表示にはしない。サンプルの個人タブ名・履歴・インストール済み拡張は実データとして表示しない。Libraryの未対応ページはFigmaの空の状態を出す。更新通知（Update Pill）はアップデートがあるときだけの表示なので出さない。

## アニメーション設定

設定の「アニメーション」→「動き」で「システムに従う／アニメーションを有効／動きを減らす」を選べる。初期値はシステムに従う。アプリだけ有効にしても、macOS全体やWebサイトのアクセシビリティ設定は変更しない。

外観とアニメーションはGeneralタブの下部に置き、既存の保存キーを維持する。Profilesは実際のプロファイル名とSpace数を表示し、追加ボタンは設定ウィンドウ内の作成シートを開く。Shortcutsは実装済みのキー操作を検索できる。トグルとドロップダウンはFigmaどおりの状態で表示し、機能のないものは操作すると「未対応」の通知を出す。設定画面自体はFigmaに合わせたダーク配色を使い、外観の選択はブラウザ本体へ適用する。Figmaにないが実際に動くExtensionsタブと外観・アニメーションの項目は残している。

## アニメーション

- タブの実際の追加・削除は180ms。行のフェード・左8ptの移動と一覧のリフロー、ページ側のフェード・6ptの移動を付ける。単なる選択やSpace切替では開閉演出をしない。
- Sidebarとページ領域は同じ曲線で連動する（表示300msスプリング、非表示200msイージング）。初期幅200ptではページの左端が8→199pt、横幅が2078→1887ptへ変わる。Sidebar自体は200msのease-outでフェードする。
- Sidebarは通常表示とホバー表示で同じビューを保持する。一時表示を固定したとき、二重のSidebarを出したり、WebViewを作り直したりしない。
- サイト操作は320msのスプリングと140msのフェード、URL欄の実際の押下は70msの表示・230msの解放フィードバック。
- コマンドバーは320msのスプリングで開き、160msのイージングで閉じる（0.96倍からの拡大縮小とフェード）。ページ側の暗転も連動する。
- Figmaの51サンプルを共通化し、5.27%のオーバーシュートを残す。デモ用タイムラインの待ち時間や無限ループは、操作待ちや自動開閉には変換しない。コマンドバーはDESIGN.md §11の値に従う。
- 動きを減らす設定では移動・拡大縮小を行わず、最終状態へ切り替える。素早い反転操作や、ホバー中にメニューを開閉した場合にも操作状態を維持する。

## 構成とアセット

`ChocoTheme`に色・寸法・文字組のトークンを集約し、`DesignIcon`と`SiteIcon`から元のアセットを利用する。Figmaから取得したSVGを未改変で残し、AppKit表示用のPDFに忠実に変換した。小数点サイズのPDFは元のページ寸法を復元してから表示する。

文字はシステムフォント（SF Pro。日本語は自動フォールバック）を使い、フォントは同梱しない（DESIGN.md §2）。アイコンはアプリに同梱し、期限付きFigma URLへの実行時アクセスは行わない。ライセンス・出典は[THIRD_PARTY.md](../THIRD_PARTY.md)を参照。

SwiftPMのResource bundleは`Contents/Resources/choco-browser_BrowserApp.bundle`へコピーする。Xcodeアプリは同じResourceファイルをメインbundleへ格納する。WebKit・Profileデータ・保存形式は変更しない。

## 操作と互換性

- サイドバー下部のLibraryボタンからArchiveへ移動する。Archiveの⌘Wは一覧を閉じ、背後のタブを残す。
- URL欄右端のサイト操作からSplitの作成・左右交換・解除へ進む。
- タブ・フォルダの右クリック操作、Space/Profile編集、Archive復元、ショートカットを継続利用できる。
- ブラウザの表示領域は既存のWKWebViewを使用する。サイドバー・Library・Splitの切替で、ページを作り直すレイアウトにはしない。
- macOS標準のウィンドウ操作は本物のOSコントロールを使う。Figmaの非アクティブ状態の丸をボタンの代わりに描かない。

検証結果は[verification.md](verification.md)に記載する。

## 基底UI部品（`DesignSystem/Components`）

Figmaの「Dialog Controls」（184:1422）と「Icons」（5:221）を、画面に依存しない部品としてまとめた。色は`ChocoTheme.Settings`／`ChocoTheme.Dialog`（`ChocoControlTheme.swift`）に、Figmaの変数名どおりに置く。

| 部品 | 引数 | Figma上の寸法・状態 |
| --- | --- | --- |
| `ChocoButton` / `.buttonStyle(.choco(...))` | `kind`（primary・secondary・blue・indigo）、`keyHint`（"ESC"などのキーチップ） | 高さ32・左右16・角8。Default／Hover／Pressed／Disabledは環境から決まる。無効はPrimary・Secondaryが不透明度45%、Blueは専用の淡色 |
| `ChocoTextField` | `tone`（settings・space）、`focus`、`onSubmit` | settingsは高さ36でフォーカス時に2ptの紫枠、spaceは高さ40で枠は変えずキャレットが`dialog/caret` |
| `ChocoColorSwatch` | 色、`isSelected`、`label`（VoiceOver用） | 32ptの領域に24ptの円、選択中は2ptのリング |
| `ChocoSlider` | `value`、`in`、`step` | 高さ20・トラック4・つまみ16。幅は親に従う（Figmaは288） |
| `ChocoIcon` | `DesignIcon(.plus)`の形で使う | Figmaの全44アイコンを意味の名前で引ける |

FigmaではPrimary・Blue・Indigoにホバー／押下専用の色がなく、無効のIndigoも通常と同じ。そのためSecondaryだけが状態で色を変える。デザインに色が追加されたら`ChocoButtonKind.palette(for:)`の1か所を直す。既存の画面（`EditorSheet`・設定の`SettingsButtonStyle`など）はこの部品へ未移行で、移行は画面ごとに外観を確認しながら行う。

## 拡張機能のインストールダイアログ（8b・8d・8e）

Figmaの「Layouts」の8a〜8e（ストアのページ・確認・読み込み失敗・追加失敗。8cの「追加しました」は廃止）に合わせた。`Features/Extensions/ExtensionDialog.swift`の`ExtensionDialog`が、380pt幅のカードを`dialog/bg`・`dialog/border`、角12、影2段で描く。ヘッダーは40ptのアイコンタイル（`text/primary`・白2ptの枠・`Icon/extension`＝`68396`）に、見出し（15 Bold）と本文（11.5・`dialog/text-muted`）を並べる。ボタンは既存の`ChocoButton`で、確認はキャンセル（`.secondary`）と追加（`.blue`）、エラーはOK（`.blue`）だけ。

- 確認（8b）は名前とバージョンだけを出す。Figmaが権限の一覧を廃止している（「権限UI廃止」）ため、権限は表示せず、インストールで要求どおり許可する。
- 成功は無言。追加できても読み込めなかったとき（8d）と追加できなかったとき（8e）だけダイアログを出す。ダウンロードの失敗では、ストアのタブの題名から取れた拡張機能名を文言に入れる。
- ブラウザウィンドウではページだけを55%暗くし、ダイアログはサイドバーの横でページの中央に置く（コマンドバーと同じ暗幕）。設定のExtensionsタブから追加したときは設定ウィンドウの上に出す。出入りの動きはFigmaに指定がないため、コマンドバーと同じ（開く320msスプリング・閉じる160ms）にした。
- 8aのストア自身のボタンから入れる。Chrome以外では無効な「Chrome に追加」を、ページ内スクリプト（`StoreInstallBridge`）で有効な「Choco に追加」に書き換える。押すとボタンがスピナーと「追加中…」になり、処理が終わると戻る。Figmaで廃止された、サイト操作パネルの「この拡張機能を追加」の行は置いていない。

## 余白（rem基準）

余白は`DesignSystem/ChocoSpace.swift`のトークンを使う。1rem=16pt。`xxs`2 / `xs`4 / `sm`8 / `md`12 / `lg`16 / `xl`24 / `xxl`32。`rem`を変えると全体の余白が連動する。**Figmaの実測値が優先**で、トークンと値が一致する箇所だけトークンを使い、スケール外の値（5・6・9・10・14・18・26・27など）はFigmaに合わせてリテラルのまま残す。サイドバーは12.5rem(200pt)・内側余白`sm`、コンテンツ余白`sm`、サイト操作は13.75rem(220pt)。

## 表示スケール

Figma の寸法（DESIGN.md）はそのまま pt として使う。`ChocoSpace.rem = 16`、`ChocoSpace.scale = 1`。

- 文書内の寸法はすべて Figma 上の値のまま。`ChocoSpace.u(_:)`・`ChocoTheme.font(_:)`・`DesignIcon` / `SpaceIcon` / `SiteIcon` は `scale` を掛ける（現在は 1）。
- 新しい frame / padding / spacing のリテラルは `ChocoSpace.u(<Figma値>)` で書く。
- 全体の大きさを変えるときは `ChocoSpace.rem` だけを変える。

## Space テーマ（DESIGN.md §7 の `Arc Tokens` モード）

`SpaceTheme`（`DesignSystem/SpaceTheme.swift`）が Dark / Indigo / Teal を表す。Space は自由色（`colorHex`）を持つため、色相からパレットを生成する（Dark / Indigo / Teal の3択に丸めない）。Indigo（243°）と Teal（180°）の色相ではFigmaのトークンとぴったり一致し、そこから±40°でなだらかに生成値へ移る。無彩色・暗い色は Dark のままで、彩度に応じて色味が乗る。`SpaceTheme` は2つのパレットを混ぜられ、Space 切替では `AppModel.spaceBlend` が旧→新を混ぜた色をウィンドウ全体（サイドバー・URL欄・Spaceラベル・お気に入り空状態・空ページのグラデーション）へ流す（スワイプ中は指の位置に追従）。`BrowserWindow` が選択中 Space から求め、`\.spaceTheme` 環境値で渡す。ウィンドウ背景（`sidebar/bg`）、URL欄・Library検索（`sidebar/field`）、お気に入り空状態（`favempty/*`）、空ページのグラデーション（`space/window-a→b`）、Space名ラベル（`space/label`）が追従し、Space 切替は 320ms のスプリングで遷移する。サイドバーのSpaceリスト（163:7447）は、新しいSpaceが右（後ろ）なら古いリストが左へ、前なら右へ184pt動き、新しいリストが反対側から入る。古いリストは0〜160msでフェードアウト、新しいリストは40ms遅れて180msでフェードイン。Spaceドットのインジケータは40ms遅れで320msのスプリングで次のドットへ動き、アイコンの濃さは40ms遅れで160msで切り替わる。空のページのグラデーションはモードごとに重ねてクロスフェードする。動きを減らす設定では全て即時。サイドバー上の横2本指スワイプ（`SpaceSwipe.swift`）では、Spaceリストとドットのインジケータ、ウィンドウの色が指に追従する。縦入力は受け付けず、横スワイプ中の縦の動きは無視する（縦スクロールの動きは横スワイプにならない）。縦か横かは動き始めの数ptで決め、横のときだけリストを動かす。リストが動く速さには上限（`SpaceSwipeRecognizer.maxSpeed` = 2400pt/秒）を設け、指が速く動いてもその速さで追いつく（フレームごとに近づける）。離したあとの切替・戻りも、その上限を超えないよう320msのスプリングを必要なだけ伸ばす（短い動きは320msのまま）。離した位置と勢いで判定するのは指の実際の位置による。離したとき、30%以上動いているか、同じ向きに素早く弾いていれば前後のSpaceへ切り替え、そうでなければ元へ戻す。最初・最後のSpaceを越えて引くとゴムのように抵抗する。

## アニメーション値（DESIGN.md §11）

開く・戻す動きは Figma のスプリング（stiffness 420 / damping 28、`FigmaSpringCurve`）、閉じる・隠す動きは `cubic-bezier(0.2, 0.8, 0.2, 1)`。コマンドバー 開く320ms／閉じる160ms（開始スケール0.96）、サイドバー 表示300ms／非表示200ms、サイト操作・新規メニューを閉じる 160ms、Space 切替 320ms。
